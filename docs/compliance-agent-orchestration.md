# 企业合规智能体编排

## 一、项目目标

制作一个可运行、可测试、可持续上传 GitHub 的智能体编排系统。

核心流程：

```text
用户提问
  ↓
意图识别
  ↓
选择并调用工具
  ↓
汇总工具结果
  ↓
模型生成结构化答案
  ↓
置信度与风险路由
  ↓
格式校验 + 引用校验
  ↓
返回答案
```

## 二、核心原则

1. 大模型负责理解、总结和表达。
2. Python 程序负责流程、权限和数据安全。
3. 每项法规结论都必须有可追溯证据。
4. 模型不能虚构法条、条款号和处罚金额。
5. 高风险结论必须允许人工复核。
6. 敏感企业数据未经批准不能发送到云端。
7. 每完成一个模块就运行测试、提交并上传 GitHub。
